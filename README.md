DEVKAZZU — Developer Portfolio

🌐 Live Website: https://devkazzu-kappa.vercel.app

A personal developer ecosystem created by Raju Mahato.

About

DEVKAZZU is a full-stack developer portfolio and content management platform built with Next.js, React, TypeScript, Tailwind CSS and PostgreSQL.

It showcases projects, applications, tools, experiments, technologies and creative work through a modern responsive interface.

Features

- Responsive developer portfolio
- Projects and applications showcase
- Interactive tools and experiments
- Search and category filtering
- Private admin dashboard
- Content management system
- Media upload and management
- Contact form and inbox
- SEO and dynamic metadata
- PostgreSQL database integration

Tech Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS 4
- PostgreSQL
- Drizzle ORM
- Zod

Getting Started

git clone https://github.com/devkazzu/devkazzu.git
cd devkazzu
npm ci

Configure your ".env" file with the required database and authentication variables.

npx drizzle-kit push
npx tsx scripts/seed.ts
npx tsx scripts/create-admin.ts
npm run dev
